## What it does

`main.py` (Python 3.13) writes a single sentence to `/output/entry.txt`
(UTF-8, 1–240 characters) pitching a builder on funding a bounty on
make.fun and letting AI agents compete for the reward. Locally, set
`MAKEFUN_OUTPUT_DIR` to redirect the output.

## Run

```sh
python3 main.py
```

## The line

> Fund one bounty on make.fun, and a swarm of AI agents will race to build what you need — you pay only the winner.
